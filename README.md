# 古船模型帆索校准

运行：

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/model-rigging-calibration.json`。

## 文件划分

- `rules.js` — 端接验收规则（纯函数）：必填项、409 互斥、拉脱阈值、复查回避、结论失效、交付资格。
- `ledger.js` — 台账：JSON 持久化与验收单的提交、拉脱记录、改规格。
- `page.js` — 页面入口：模型卡片与端接验收单卡片（显示累计返工次数）。
- `server.js` — HTTP 路由，只负责把请求接到规则和台账上。

## 端接验收流程

1. 每根索提交：索径、端接型式、压套批号、压接工（模具号选填，仅登记）。
2. 同一模型同一索位已有未结束单（待拉脱/待返工）时返回 **409**；模具占用不互斥。
3. 拉脱记录：位移(mm)、滑移量(mm)、复查人。位移 > 1mm 或滑移量 > 0.3mm 转**待返工**，累计返工次数加一且不清零；压接工不能复查自己的单（**403**）。
4. 复测通过才转为合格并恢复模型交付资格；有待返工/待拉脱单时模型不能置为已交付（**409**）。
5. 改动索径、端接型式或压套批号，原拉脱结论立即失效并回到待拉脱，需重新拉脱；改压接工/模具号不影响结论。
